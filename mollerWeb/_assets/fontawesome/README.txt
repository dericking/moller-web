Font Awesome Free 6.5.1 — trimmed webfont subset for this site.

Icons: CC BY 4.0; fonts: SIL OFL 1.1; code: MIT. See LICENSE.txt.
https://fontawesome.com

This is not the full Free kit. Only glyphs used by site chrome (sidebar,
home cards, table headers) are in the two .woff2 files. Brands and v4
compatibility fonts are omitted.

Used now (solid unless noted):
  book, book-open, bullseye, chalkboard-user, chart-bar, chart-line,
  eye, file-lines, globe, link, location-dot, magnet, microchip,
  pencil, tags, user, users
  calendar (regular)

To add an icon, restore that glyph in the subset (or drop in the full
6.5.1 webfonts + CSS) and add a .fa-*::before rule. See root README.md.
